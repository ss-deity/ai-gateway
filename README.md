# AI Gateway

A unified AI Gateway built with NestJS and TypeScript.

## Features

- 🤖 OpenAI Compatible API
- 🌐 Multi-model Support (DeepSeek / Qwen / OpenAI / Kimi)
- ⚡ Streaming Response (SSE)
- 🔀 Model Routing
- 🔐 JWT Authentication
- 💬 Conversation Management
- 📝 Prompt Management
- 📊 Rate Limiting & Logging
- 🐳 Docker Ready
- 🚀 CI/CD Ready
- 🧩 Extensible for RAG, Agent, and MCP
